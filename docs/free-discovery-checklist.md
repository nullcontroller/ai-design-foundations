# Free discovery checklist

Codeだけでは完了できない無料施策の確認表です。アカウント設定や外部Profileの変更は、所有者が内容を確認して実施します。

## Google Search Console

- [ ] URL-prefix Propertyを追加
- [ ] `PUBLIC_GOOGLE_SITE_VERIFICATION`をGitHub Actions Variableへ設定
- [ ] SiteをVerify
- [ ] `sitemap.xml`を送信
- [ ] Home、Career、AI Design、ArticlesをURL Inspectionで確認

## Bing Webmaster Tools

- [ ] Google Search ConsoleからImport、またはSiteを追加
- [ ] 必要な場合は`PUBLIC_BING_SITE_VERIFICATION`を設定
- [ ] Sitemapを送信

## GitHub Profile

- [ ] Website URLを`https://nullcontroller.github.io/ai-design-foundations/`へ設定
- [ ] BioとPinned Repositoryが現在のPositioningと一致するか確認

## GitHub Repository

- [ ] About欄のWebsiteへ公開Siteを設定
- [ ] DescriptionをRosariumの内容が自然に分かる文章にする
- [ ] Topicsを実内容に合わせて設定する

Topics候補：`applied-ai`、`system-architecture`、`rag`、`llm`、`knowledge-management`、`astro`。

## LinkedIn

- [ ] Contact InfoまたはFeaturedからRosariumへLink
- [ ] 共有時のOGP表示を確認

## Zenn Profile

- [ ] ProfileからRosariumへLink
- [ ] 既存記事はDiscovery入口として維持
- [ ] 新規ContentではRosariumを正本として明示

## 定期確認

- [ ] Search Console / BingのIndex CoverageとSitemap Errorを確認
- [ ] Feed URLと主要外部導線を確認
- [ ] GitHub ActionsのQuality Gateが成功していることを確認
